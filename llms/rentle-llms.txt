# Rentle (Twice Commerce)

> Rentle, now Twice Commerce, is a circular-commerce platform for rentals, resale, and subscriptions founded in Helsinki in 2018. Its Twice Admin API (OpenAPI 3.0.0, version 2023-02-01) lets merchants read and manage categories, customers, inventory, products, orders, stores, discount codes, SKUs, API keys, and webhooks, with outbound webhooks for order and product events. This llms.txt is generated by the API Evangelist enrichment pipeline from the provider's public catalog.

## APIs

- [Twice Admin API (reference)](https://api.rentle.io/admin/): Redoc reference for the current merchant Admin API.
- [Twice Admin API (OpenAPI)](https://api.rentle.io/admin/swagger.json): OpenAPI 3.0.0 specification, version 2023-02-01.
- [Legacy Rentle API](https://api.rentle.io/docs): Superseded legacy API; new features land only on the Admin API.
- Base URL: https://api.twicecommerce.com/admin
- Auth: HTTP Basic (API key id = username, API key secret = password), scoped per key.
- Versioning: date-based, required header X-Rentle-Version: 2023-02-01.
- Rate limiting: leaky bucket (capacity 50, 1 request/second), HTTP 429 on exceed.
